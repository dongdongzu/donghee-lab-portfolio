모델은 수업용 `tsmc018.lib` 사용 (NMOS Vth 약 0.37 V, VDD 1.8 V)

### 1-0. 읽기 트랜지스터 특성 — `02_read_iv.cir` ✅

  - 0.45 V부터 전류 흐름, 0.65~1.1 V 거의 직선, 1.2 V 이상 휘어짐
  - 85°C에서 전류 20% 이상 감소 → 기준 열 보상으로 상쇄 가능
- 4레벨 저장 전압 결정 (전류 0 / 35 / 70 / 105 µA 근처)

| 가중치 | 저장 전압 |

| 0 | 0 V |
| 1 | 0.73 V |

## 2단계. 연산 회로 (LTspice)

### 2-1. 비트라인 곱셈-누산
- [ ] 셀 4개를 RBL 하나에 연결
- [ ] 가중치·입력 조합별로 실제 전류 합 vs 단순 합 비교 (선형성)

### 2-2. 음수 가중치 (차동 구조)
- [ ] 양수 열, 음수 열 전류 차이로 부호 표현

$$I_{out} = I_{BL+} - I_{BL-}$$

### 2-3. 기준 열 보상
- [ ] 같은 시점에 최대 가중치를 써둔 기준 열 추가

$$y = \frac{I_{BL}}{I_{REF}}$$

- [ ] 시간 경과, 온도 변화에도 비율이 일정한지 확인 → 보상 전후 비교 그래프

### 2-4. 주변 회로 (가점, 시간 되면 / 우선순위 순)
- [ ] 쓰기 드라이버: 저항 사다리 + 2비트 MUX
- [ ] 딕슨 차지펌프로 WWL용 VPP 공급 (수업 회로 재사용)
- [ ] 디코더로 WWL·RWL 행 선택 (수업 회로 재사용)
- [ ] 읽기단: RBL 0.1 V 고정 + 전류 → 전압 변환

### 2-5. 비용 계산
- [ ] 면적: 64열 기준 기준 열 1개 → 약 1.6%
- [ ] 전력: 읽기 에너지, 리프레시 주기에 따른 리프레시 전력

## 4단계. AI 실험 (Python)

- [ ] 4-1. 환경 준비 (PyTorch, numpy, matplotlib)
- [ ] 4-2. MNIST 784-64-10 학습, 입력 이진화(밝기 128 기준) → 기준 정확도
- [ ] 4-3. 가중치 2비트 양자화 (-3~+3, 차동으로 양수·음수 각각 0~3)
  - 정확도 많이 떨어지면 양자화 인식 학습(QAT)
- [ ] 4-4. 셀 행동 모델

  2. 저장 전압 + 경과 시간 + 온도 → 현재 저장 전압
  3. 현재 저장 전압 + Vth 편차 → 읽기 전류
- [ ] 4-5. CIM 추론: 곱셈-누산을 셀 전류 합으로 계산, 시드 여러 개 반복
- [ ] 4-6. 비교 실험 (핵심 그래프)

  - 보상 없음 / 기준 열 보상 / 보상 없음 + 리프레시
  - 25°C, 85°C
  - 결론 숫자: 정확도 90% 이상 유지 시간이 몇 배 늘었는지
- [ ] 4-7. (가점) AI 설계 최적화: 레벨 전압 배치·기준 열 개수 최적화
