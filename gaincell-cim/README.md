## 배경지식

- **CIM (Compute-In-Memory)**
  - 메모리에서 데이터를 꺼내 프로세서로 옮기지 않고 메모리 안에서 바로 곱셈·덧셈을 하는 방식임
  - AI 연산의 대부분이 곱셈-누산(MAC)이라 전력·속도 면에서 유리함

- **2T 게인 셀**
  - 트랜지스터 2개로 만든 DRAM 계열 셀임
  - 커패시터 대신 읽기 트랜지스터의 게이트에 전하를 저장하고, 저장 전압에 따라 읽기 전류가 달라짐
  - 읽어도 데이터가 지워지지 않는 비파괴 읽기라서 CIM에 잘 맞음

- **멀티레벨**
  - 한 셀에 0/1 두 단계가 아니라 4단계 전압을 저장해서 2비트를 담음
  - 대신 레벨 간격이 좁아져서 누설에 훨씬 민감해짐

- **리텐션 문제**
  - 저장 노드가 떠 있는 노드라서 누설 전류 때문에 전압이 서서히 떨어짐
  - 멀티레벨에서는 조금만 떨어져도 인접 레벨과 겹쳐서 가중치 값이 틀어짐
  - 결국 시간이 지나면 AI 추론 정확도가 떨어짐 → 이걸 정량적으로 보여주고 보상하는 게 이번 프로젝트 목표임

## 전체 구조

```
[LTspice] 2T 셀 + 비트라인 MAC 회로 설계
   ↓  셀 특성 추출 (저장 전압별 전류, 시간별 전압 하강, Vth 편차)
[Python] 셀 행동 모델 구현
   ↓
[Python] MNIST 신경망 가중치를 CIM 모델에 매핑해서 추론
   ↓
[결과] 시간 경과에 따른 정확도 저하 → 보상 적용 시 정확도 회복
```

- LTspice: 회로가 실제로 동작하는지 검증
- Python: 그 회로로 AI를 돌렸을 때 결과 확인

## 회로 설계

### 셀 구조 (NMOS 2T 게인 셀)
- **쓰기 트랜지스터 MW**
  - 게이트는 쓰기 워드라인(WWL), 저장 노드(SN)에 가중치 전압을 씀
  - 누설을 줄이려고 Vth 높은 소자 사용
  - 쓰기 때 WWL을 VDD보다 높게 올려서 Vth만큼 전압 깎이는 것 방지
- **읽기 트랜지스터 MR**
  - 게이트가 SN이고, 저장 전압에 따라 읽기 전류가 정해짐

### 연산 방식
- 가중치: SN 전압 4단계 (2비트)
- 입력: 읽기 워드라인(RWL) on/off (1비트)
- 같은 비트라인(RBL)에 연결된 셀 전류가 합쳐져서 곱셈-누산이 됨

$$I_{BL} = \sum_{i} x_i \cdot I_{cell}(V_{SN,i})$$

### MR 선형 영역 동작
- MR이 포화 영역이면 전류가 저장 전압의 제곱에 비례해서 가중치가 비선형으로 왜곡됨
- RBL 전압을 작게(약 0.1 V) 고정해서 선형 영역에서 동작시키면 전류가 저장 전압에 거의 비례함

$$I_{cell} \approx \mu C_{ox} \frac{W}{L} \left(V_{SN} - V_{th}\right) V_{DS}$$

### 음수 가중치 (차동 구조)
- 양수용·음수용 두 열을 두고 두 비트라인 전류 차이로 계산함

$$I_{out} = I_{BL+} - I_{BL-}$$

### 보상 (기준 열 비율 계산)
- 가중치 쓸 때 같은 시점에 최대 가중치를 기준 열에도 써둠
- 출력을 기준 열 전류로 나누면 모든 셀이 같이 겪는 하강(누설, 온도)이 상쇄됨

$$y = \frac{I_{BL}}{I_{REF}}$$

- 비용: 열 하나 추가 (64열 기준 면적 약 1.6%)

### 소자 모델
- PTM (Predictive Technology Model) 공개 모델 사용, 포스터에 출처 표기
- 누설이 핵심이라 저전력(LP) 계열 모델 사용 예정

## AI 파트 상세

1. MNIST 손글씨 분류 신경망 학습 (784-64-10 정도, PyTorch)
2. 가중치를 2비트(4단계)로 양자화
3. LTspice에서 뽑은 셀 특성으로 행동 모델 만들고, 가중치를 셀 전류로 변환
4. 시간 t에 따른 저장 전압 하강 + Monte Carlo 편차 반영해서 추론
5. 보상 방식별 정확도 비교
   - 보상 없음
   - 기준 열 보상
   - 리프레시
