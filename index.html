01 / EXCEL · CMOS VTC
CMOS VTC / PARAMETER SUMMARY
CMOS · EXCEL01

CMOS VTC 분석 자동화

LTspice로 만든 CMOS의 VTC를 엑셀에서 이어서 볼 수 있도록 분석표를 구성했습니다. 입력·출력 전압을 바꾸면 기울기와 노이즈 마진을 함께 확인하는 흐름입니다.

LTspiceExcelVTCNoise Margin
세부 메모

정리한 항목: Vin·Vout 입력표, 중앙 차분 기울기, 절대 기울기 변화, 문턱 전압과 노이즈 마진 요약. 다음 확인: 실제 시뮬레이션 값을 넣어 계산 결과와 그래프가 맞는지 대조합니다.

02 / GAA STRUCTURE
GAA · PAPER NOTES02

GAA 구조별 성능 비교

나노와이어와 나노시트는 모양만 다른 걸까? 게이트가 채널을 잡는 방식, 전류, 공정 난도를 논문 표와 함께 비교했습니다.

GAA FET논문 리딩구조 비교
세부 메모

비교 기준: 채널 단면, 게이트 제어력, 유효 채널 폭, 구동 전류. 숫자 하나로 우열을 정하기보다 각 논문의 구조와 조건이 같은지부터 확인했습니다.

CMOSSTI공정 해석시각화
세부 메모

다시 그린 내용: Well과 STI 위치, 게이트 형성 순서, 각 단계 뒤 단면이 어떻게 달라지는지. 위 그림은 흐름을 보여주는 간단한 표식이며, 실제 공정 단면도와는 구분했습니다.

04 / MOSFET RESPONSE
MOSFET · RESPONSE04

회로 해석과 응답 분석 노트

공통 소스 증폭기의 주파수 응답을 살펴보고, 회로도와 시뮬레이션 결과가 어떻게 이어지는지 정리한 공부 메모입니다.

MOSFET회로 시뮬레이션주파수 응답
세부 메모

이 그래프는 실제 측정 결과가 아니라 회로 응답을 설명하기 위한 개념 그림입니다. 실제 회로도와 시뮬레이션 캡처는 정리되는 대로 별도 기록으로 추가할 예정입니다.

※ 각 카드의 도식은 이해를 돕기 위한 그림입니다. 실제 회로도·원본 엑셀·측정 그래프가 연결된 작업은 따로 표시하고, 아직 없는 자료를 완성물처럼 소개하지 않습니다.

내가 공부하는 방식

헷갈리면,
다시 그려본다.

회로는 시뮬레이션해 보고, 공정은 단면으로 그려봅니다. 숫자가 반복되면 표로 정리하고, 이해가 안 된 부분은 노트에 남깁니다.
